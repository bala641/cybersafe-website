Quick Start Guide

1

Download & Extract

Download the ZIP file and extract to any folder. No installation needed for portable use.

2

Run Installer

Double-click install.bat for automatic setup, or launcher.vbs for instant launch.

3

Select Interface

Choose your network interface from the dropdown menu in the application header.

4

Start Monitoring

Click "Start Capture" and watch live packets, threats, and network metrics appear instantly!

📝 Note: Administrator privileges required for packet capture. Right-click and "Run as Administrator" if needed.

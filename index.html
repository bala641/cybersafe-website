about cybersafe

CyberSafe is an advanced network monitoring platform designed for security professionals and network administrators. Built with performance and real-time analysis in mind.

Monitor packets in real-time, detect threats instantly, and maintain complete visibility over your network infrastructure with an intuitive desktop GUI.

// tech stack

Python 3.9+ Scapy CustomTkinter Matplotlib SQLite Flask Real-time Analytics Threat Detection

features

Real-Time Monitoring

Live packet capture with instant analysis and detailed protocol breakdown across all network interfaces.

Threat Detection

Advanced anomaly detection that identifies port scans, DDoS patterns, and suspicious traffic automatically.

Port Monitoring

Track open ports, active connections, and network services across your entire infrastructure.

Live Analytics

Real-time dashboards with traffic graphs, protocol distributions, and historical trend analysis.

Lightweight Engine

Optimized packet processing engine with minimal CPU and memory footprint for 24/7 operation.

Export Reports

Export detailed reports in JSON, PDF, Word, and plain text formats for documentation and audits.

# CyberSafe Website

Official landing page for **CyberSafe** - Professional Network Traffic Monitoring & Threat Detection Software.

🔗 **Live Site:** [https://cybersafe.vercel.app](https://cybersafe.vercel.app)

## 🌐 About

This is a clean, modern single-page website built with:
- Pure HTML5
- CSS3 (no frameworks)
- Vanilla JavaScript
- **Zero dependencies** (perfect for Vercel)

## 📁 Structure

```
cybersafe.site/
├── index.html      # Main landing page
├── style.css       # All styles
├── script.js       # Smooth scroll & animations
├── vercel.json     # Vercel configuration
├── .gitignore      # Git ignore rules
└── README.md       # This file
```

## 🚀 Deploy to Vercel

### Option 1: Automatic (Recommended)

1. Push to GitHub:
```bash
cd cybersafe.site
git add .
git commit -m "CyberSafe landing page"
git push origin main
```

2. Import in Vercel:
   - Go to [vercel.com](https://vercel.com)
   - Click "New Project"
   - Import from GitHub
   - Deploy!

### Option 2: Vercel CLI

```bash
npm i -g vercel
cd cybersafe.site
vercel --prod
```
